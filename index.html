Ollie Ocean Shorts Uploader

A private, single-user command-line tool that uses YouTube API Services (YouTube Data API v3) to upload the operator's own short videos to the operator's own YouTube channel, @ollieoctopusworld, and to read statistics of those videos.

It has no public user interface and no users other than its operator. It does not collect or share data about any other person.
