Privacy Policy — Ollie Ocean Shorts Uploader

Last updated: October 24, 2026

What this is. "Ollie Ocean Shorts Uploader" is a private, single-user command-line script operated by one individual developer. It is not offered to the public and has no other users.

Data accessed

Through the YouTube Data API v3 the script accesses only the operator's own YouTube channel (@ollieoctopusworld): it uploads the operator's own videos (videos.insert), may set thumbnails, and may read statistics of the operator's own videos (videos.list, channels.list).

Data NOT accessed

The script does not collect, read, store, or share any data about other YouTube users, viewers, commenters, or subscribers. It does not perform actions on any other channel and does not use the API to artificially increase views, likes, subscribers, or other engagement.

Storage and security

The OAuth token for the operator's own Google account is stored only in a local file on the operator's computer (file permissions restricted to the owner). No data is transmitted to any third party, sold, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The script also complies with the YouTube API Services Terms of Service. Google's privacy policy: policies.google.com/privacy.

Revoking access

The operator can revoke the script's access at any time at myaccount.google.com/permissions.

Questions: open an issue in this GitHub repository.
